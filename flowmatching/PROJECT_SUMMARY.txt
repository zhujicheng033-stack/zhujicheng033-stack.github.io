PROJECT STRUCTURE
================================================================================

data/
  synthetic_data_generator.py (157 lines)
    - Generates toy perturbation data with P0/P_T/P1 states
    - Multi-drug  multi-cell-line  multi-timepoint structure
    - Outputs AnnData format

models/
  stage1_featuremap.py (186 lines)
    - Manifold extraction: PCA + KMeans clustering
    - Outputs: state labels, transition scores, X_pca

  stage2_cfm.py (285  CORE MODULElines) 
    - CFMModel: unified flow matching with B    - Velocitymlpzier anchors: neural network velocity field v_
    - CFMTrainer: training loop with Adam optimizer

  stage3_attribution.py (213 lines)
    - Jacobian-based gene importance scoring
    - Static importance via DE analysis
    - Three-way gene decomposition

  components/
    bezier.py (145 lines)
      - Quadratic Bzier: x(t) = (1- + 2t(1-t)x_T + xxtxxt)
      - Velocity: v(t) = 2(1-t)(x_T-) + 2t(-x_T)xx
      - Utilities for curve evaluation

    losses.py (236 lines)
      - L_flow: velocity matching
      - L_geom: geometric constraints with transition scores
      - L_context: cross-context consistency
      - L_smooth: Jacobian regularization

validation/
  metrics.py (242 lines)
    - MMD (Maximum Mean Discrepancy)
    - Wasserstein-2 (sliced Wasserstein approximation)
    - Trajectory correlation
    - State purity, gene recovery

experiments/
  config.yaml (28 lines)
    - All hyperparameters in one place
    - Easy to tune without code changes

  run_pipeline.py (283 lines)
    - Main runner connecting all 5 stages
    - Stage 0: Data preparation
    - Stage 1: Manifold extraction
    - Stage 2: CFM training
    - Stage 3: Gene attribution
    - Stage 4: Validation

KEY DESIGN PRINCIPLES
================================================================================

 Modularity
  - Each stage completely independent
  - Can modify any module without affecting others
  - Each has internal tests (if __name__ == "__main__")

 Configuration-driven
  - All hyperparameters in config.yaml
  - No hardcoding
  - Easy to reproduce results

 Progressive development
  - Stage 0: Generate toy data
  - Stage 1: Validate manifold extraction
  - Stage 2: Train CFM (the core algorithm)
  - Stage 3: Gene analysis
  - Stage 4: Quality validation

 Tensor-based computation
  - PyTorch for all numerical operations
  - GPU support ready (device parameter)
  - Automatic differentiation for Jacobians

COMMON ISSUES & SOLUTIONS
================================================================================

Issue: ModuleNotFoundError: anndata
Solution: pip install anndata

Issue: CUDA out of memory
Solution: Reduce batch_size in config.yaml

Issue: Loss not converging
Solution: Increase learning_rate or reduce lambda_smooth

Issue: Jacobian computation slow
Solution: Stage 3 computes per-gene derivatives (slow by design)
         Can be optimized by batching if needed
