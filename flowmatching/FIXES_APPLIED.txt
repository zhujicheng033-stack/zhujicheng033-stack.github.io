TRANSITION SCORE SEMANTICS (Bug 3)
──────────────────────────────────

Formula: s(x) = d1 / (d2 + ε)

Interpretation:
  d1 = distance to nearest cluster center
  d2 = distance to 2nd nearest cluster center

Cases:
  1. Stable cell near cluster A, far from all others
     d1 = 0.1,  d2 = 5.0
     s(x) = 0.02  ← LOW (cell is stable, suppress velocity)

  2. Transition cell between clusters A and B
     d1 = 2.0,  d2 = 2.5
     s(x) = 0.80  ← HIGH (cell is in flux, allow velocity)

  3. Very stable cell
     d1 = 0.01, d2 = 10.0
     s(x) = 0.001 ← VERY LOW (strongest stability)

Used in L_geom: E[(1-s(x))² ‖v‖]
  → When s=0 (stable): (1-0)²‖v‖ = ‖v‖ allowed
  → When s=1 (transition): (1-1)²‖v‖ = 0 suppressed

LOSS FUNCTIONS (Bugs 4-5)
─────────────────────────

L_flow: MSE(v_pred, v_target)
        Standard flow matching objective

L_geom: E[(1-s(x))² ‖v‖]
        Geometric constraint from manifold structure

L_context: mean(var(v_context_stack, dim=0))
          Variance of context-head outputs across heads
          → Encourages consistency in similar backgrounds

L_smooth: mean(E[‖J·v_random‖²])
         Hutchinson trace estimate of ‖J‖_F²
         → Regularizes Jacobian magnitude

Total: L = L_flow + 0.1·L_geom + 0.01·L_context + 0.001·L_smooth

VELOCITY FIELD ARCHITECTURE
──────────────────────────

v_θ(x,t,c) = v_shared(x,t) + Σ_k α_k(c)·v_context_k(x,t,c)

Components:
  v_shared: Context-independent base field
    Input: [x, t]
    Output: (B, D)

  v_context_heads: List of context-specific networks
    Input: [x, t, c]
    Output: (B, D)

  α_weights: Softmax gating
    Input: c
    Output: softmax weights across heads

Interpretation:
  - Shared component captures universal transition dynamics
  - Context heads capture drug/cell-line specific variations
  - Alpha weights show which contexts dominate
